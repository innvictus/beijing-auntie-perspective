## 一、现在的问题（猜的，但估计八九不离十）

| 问题 | 表现 | 后果 |
|------|------|------|
| 网图太多 | 百度搜的夕阳、花朵、风景 | 读者一看就不是自己人，没信任感 |
| 文字图泛滥 | "早安""晚安"类图文 | 微信算法降权，读者审美疲劳 |
| 没人出镜 | 全是风景和表情包 | 没有记忆点，记不住你是谁 |
| 封面不吸引 | 随便一张图就做封面 | 文章再好也没人点 |
| 图片太"精美" | 滤镜太重，像影楼风 | 1300退休金的人不这样过日子，假 |

## 二、配图三大原则

### 原则1：真实 > 精美

**对的：** 自己家厨房拍的晚饭、菜市场买菜的实拍、自己穿的衣服用的东西

**错的：** 百度搜的"老年人吃饭"、加了滤镜的风景照、网上下载的花朵图

### 原则2：人出镜 > 没人

为什么必须出人：有人就有信任，有人就有辨识度，有人就有情感连接。

**如果不想露脸也有的救：**
- 拍背影/侧脸
- 拍手的动作（切菜、择菜、算账）
- 拍走路/买菜的过程（不拍正脸）

**总比没有强。**

### 原则3：手机拍 > 相机拍

手机拍出来的"不完美感"，反而更真实。相机太清晰了，读者会觉得"这是专业团队做的"。

## 三、各场景配图指南

| 场景 | 配图建议 | 拍摄方法 |
|------|---------|---------|
| 写菜价 | 拍菜市场的菜+价格牌 | 手机横屏，自然光线 |
| 写做饭 | 拍切菜/炒菜/成品三连 | 手机俯拍，注意不要手抖 |
| 写省钱 | 拍日常记账本+零钱 | 特写，拍清楚数字 |
| 写情感 | 拍自己散步/坐在公园 | 远景，自然 |
| 写政策 | 拍政策文件截图+自己标注 | 中间加手写圈注 |
| 写日常 | 拍小县城的街景/小店 | 随手拍，别摆拍 |

## 四、封面图公式

公众号封面图最重要——决定了文章被不被点开。

> **真人 + 情绪表情 + 大字标题**

示例：
- 您站在菜市场门口，表情认真，上面大字：「1300退休金够不够花？」
- 您坐在家里算账，表情感叹，上面大字：「我给您算笔账！」

**封面禁忌：**
- 纯风景图做封面（没人点）
- 纯文字做封面（看都不想看）
- 网上找的老太太图片（一眼假）
- 颜色太暗（老年人看不清楚）

## 六、贴图自查清单

每次发文前，对照这个清单：

- [ ] 图片是今天/最近拍的吗？
- [ ] 图片里有真实的人/场景吗？
- [ ] 图片和文章内容相关吗？
- [ ] 封面有没有大字标题？
- [ ] 图片色彩够亮（老年人视力不好）吗？
- [ ] 如果是一组图，有没有叙事顺序？
