# 06-timeline.md - 北京大妈有话说 · 时间线

| 时间 | 事件 | 对IP的影响 |
|------|------|-----------|
| ~2015-2016 | 创始人边长勇从传统媒体转型新媒体，偶然发现老年内容蓝海 | 定位起点 |
| ~2016 | 找到IP核心扮演者阮雅青（孙大妈），IP人格化完成 | 人设定型 |
| ~2017 | "北京大妈有话说"微信公众号上线 | 内容平台建立 |
| ~2018 | 短视频形式上线，定位"中国首档老年人评论节目" | 媒体形态扩展 |
| 2018-2019 | 面临变现危机，尝试多种变现模式 | 商业模式探索 |
| ~2019 | 与北京市老龄办合作，获得政府背书 | 权威性提升 |
| ~2020 | 举办首届"大妈春晚"，IP文化符号化 | 品牌升级 |
| 2020-2021 | 短视频平台（抖音、快手）大规模扩展 | 跨平台布局 |
| 2021 | 一条短视频获赞56万+，直播带货超百万 | 商业验证 |
| ~2022 | 被行业媒体作为银发网红标杆案例报道 | 行业地位确认 |
| 2023+ | 直播带货成为主要变现方式 | 商业成熟 |
| 2025-2026 | 持续活跃，维持银发赛道头部位置 | 持续运营 |
